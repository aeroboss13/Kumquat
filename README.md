# Pabions

Офлайн‑конвертер файлов для macOS, который работает без кликов. Начните перетаскивать файл, нажмите клавишу, бросьте файл на сектор колеса, и результат появится рядом с оригиналом. Ничего не загружается в интернет: вся обработка идёт на вашем Mac.

Внутри приложение называется **Kumquat**.

## Как это работает

1. Начните перетаскивать любой файл (из Finder, с рабочего стола, из другого приложения).
2. Не отпуская кнопку мыши, нажмите клавишу:

| Клавиша | Колесо |
|---|---|
| **⇧ Shift** | Конвертация форматов. Повторное нажатие открывает следующую страницу вариантов |
| **⌘ Command** | Инструменты: сжатие, вырезание фона, размытие лиц, OCR, склейка и другие |
| **⌃ Control** | Действия с файлом: AirDrop, плавающая полка, копировать, переместить, скопировать путь, открыть в Терминале |

3. Бросьте файл на нужный сектор. Результат сохранится рядом с оригиналом, исходный файл не меняется. Бросок в центр колеса отменяет действие.

Ход работы показывается в уведомлении в правом верхнем углу экрана, по клику результат открывается в Finder. Если перетаскивание неудобно, есть обычное окно: бросьте в него файлы и выберите действие кнопкой. Особых разрешений (Accessibility, Input Monitoring) приложению не нужно.

## Возможности

**Изображения**
- Конвертация: JPG, PNG, WebP, HEIC, TIFF, AVIF, BMP, GIF, PDF; SVG читается как входной формат.
- Инструменты: сжатие, уменьшение вдвое, удаление EXIF и геометок, автоулучшение, вырезание фона, размытие лиц и текста, рамка с градиентом, квадратная обрезка, поворот, отражение, ч/б, распознавание текста в .txt.
- Несколько картинок: коллаж или один PDF.

**Видео и аудио** (через ffmpeg, с индикатором прогресса)
- Видео: MP4, MOV, MKV, WebM, AVI, WMV, GIF, MP3.
- Аудио: MP3, M4A, WAV, FLAC, OGG, Opus, AIFF, WMA.
- Инструменты: сжатие (H.264, до 1080p), извлечение звука, удаление звука, GIF, половинное разрешение, поворот, ускорение в 2 раза, стоп‑кадр, выравнивание громкости, склейка нескольких файлов.

**PDF**
- В DOCX, Pages, JPG, PNG (300 DPI), EPUB, TXT, Markdown, RTF.
- Сжатие, разбивка по страницам, поворот, склейка нескольких PDF, распознавание текста в сканах.

**Документы:** DOCX, RTF, ODT, TXT, Markdown, HTML, EPUB, Pages конвертируются друг в друга и в PDF.

**Таблицы:** CSV, TSV, XLSX, ODS → CSV, TSV, XLSX, JSON, HTML, PDF.

**Презентации:** PPT, PPTX, Key → PDF, JPG, PNG (нужен Keynote или LibreOffice).

**Субтитры:** SRT ↔ VTT, экспорт в TXT.

**Архивы:** упаковка в ZIP, TAR, TAR.GZ; распаковка ZIP, TAR, GZ, а также RAR и 7z (через 7z).

**Действия с файлами:** AirDrop, плавающая полка, из которой файлы можно перетащить в другое приложение, копирование в буфер, перемещение в папку, копирование полного пути, открытие папки в Терминале или iTerm2.

## Установка

### Требования
- macOS 15 или новее, Mac на Apple silicon
- Xcode (или Command Line Tools) со Swift 6.2+
- [Homebrew](https://brew.sh) для дополнительных утилит

### Шаги

```bash
git clone https://github.com/aeroboss13/Pabions.git
cd Pabions
brew install ffmpeg
./scripts/build-app.sh --install
```

Скрипт соберёт приложение, скопирует его в `~/Applications/Kumquat.app` и запустит. После запуска в строке меню появится иконка.

Чтобы просто собрать `.app` без установки (результат в `build/Kumquat.app`):

```bash
./scripts/build-app.sh
```

### Дополнительные утилиты (по желанию)

| Утилита | Для чего | Установка |
|---|---|---|
| ffmpeg | аудио и видео (обязательна для них) | `brew install ffmpeg` |
| cwebp | более качественный экспорт WebP | `brew install webp` |
| avifenc | экспорт AVIF, если система не умеет сама | `brew install libavif` |
| 7z | распаковка RAR и 7z | `brew install sevenzip` |
| Pages | экспорт и чтение файлов .pages | App Store |
| Keynote или LibreOffice | презентации → PDF | App Store / `brew install --cask libreoffice` |

Какие утилиты найдены, видно в настройках приложения, в разделе Helpers.

## Настройки

Иконка в строке меню → **Settings…**:
- клавиши для каждого колеса (Shift, Command, Control, Option или выключено);
- куда сохранять результат: рядом с оригиналом, в «Загрузки» или в свою папку;
- качество изображений;
- показывать результат в Finder, звук по завершении;
- запуск при входе в систему;
- открывать папки в iTerm2 вместо Терминала.

## Разработка

```bash
swift build          # отладочная сборка
swift test           # тесты конвертеров на настоящих файлах (для аудио и видео нужен ffmpeg)
```

Структура:
- `Sources/Kumquat/Model.swift` — типы файлов и каталог операций для каждого колеса
- `Sources/Kumquat/Engine.swift` — запуск операций, именование файлов, архивы
- `ImageEngine.swift`, `MediaEngine.swift`, `DocumentEngine.swift`, `PDFEngine.swift` — конвертеры
- `Wheel.swift` — отслеживание перетаскивания, радиальное колесо, уведомления
- `Services.swift`, `FloatShelf.swift`, `App.swift` — настройки, задачи, действия с файлами, окна и меню

## Ограничения

- Нет интерактивных редакторов (обрезка с выбором области, аннотации, правка метаданных, обрезка видео по таймлайну): все инструменты срабатывают сразу, одним броском.
- Из XLSX читается только первый лист.
- Без Keynote и LibreOffice из презентации можно получить только картинку первого слайда.
- Приложение подписано локально (ad‑hoc). Если вы перенесёте собранный `.app` на другой Mac, Gatekeeper может его заблокировать. Проще собрать приложение на том Mac из исходников.
