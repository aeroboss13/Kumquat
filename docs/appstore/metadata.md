## App Review Information → Notes (по-английски, для ревьюера)

```
Kumquat is a menu bar utility (LSUIElement), so it shows no Dock icon. On first launch it opens its main window.

HOW TO TEST
1. In the window, click "Allow…" and choose the home folder. This grants the sandbox permission to save converted files next to the originals (security-scoped bookmark). Without it, Kumquat asks per folder or saves to Downloads.
2. In Finder, start dragging any image. While still holding the mouse button, tap Shift. A wheel opens around the cursor.
3. Drop the file on "PNG". A PNG copy appears next to the original and a notification shows in the top-right corner.
4. Repeat with Command (tools, e.g. "Erase all metadata") and Control (AirDrop, copy, move…).
5. Alternatively drop files into the Kumquat window and click a format.

The drag gesture uses no Accessibility or Input Monitoring permission: it reads NSEvent.pressedMouseButtons, NSEvent.modifierFlags and the drag pasteboard's change count.

Audio and video are converted by an embedded FFmpeg helper executable (Contents/MacOS/ffmpeg), built from the official FFmpeg 9.0.2 release under the LGPL 2.1, without GPL or non-free components, signed with the app-sandbox and inherit entitlements. Its licence and source information are in Settings → Open-source licenses.

No account, no network access, no data collection.
```
