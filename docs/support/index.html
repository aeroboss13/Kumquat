How to use Kumquat

Start dragging any file in Finder or on the desktop. While still holding the mouse button, tap a key:

  • ⇧ Shift — convert to another format
  • ⌘ Command — tools: compress, erase metadata, remove background and more
  • ⌃ Control — actions: AirDrop, floating shelf, copy, move, copy path, Terminal

Drop the file on a slice of the wheel. The result appears next to the original. Prefer clicking? Open the Kumquat window from the menu bar icon and drop files there.

Frequently asked questions

The wheel doesn't appear when I tap Shift.

Tap the key while you are already dragging a file, with the mouse button held. Check that the gesture is on in the menu bar icon, and that the keys in Settings match the ones you press. Drags of text, links or e-mail attachments that are not files don't open the wheel.

Why does Kumquat ask for access to a folder?

Mac App Store apps run in a sandbox and may only write where you allow. The first time a result is saved into a folder, macOS shows a standard folder panel; click Allow Access. If you decline, the result is saved to Downloads. You can review allowed folders in Settings → File access.

Where are my converted files?

Next to the original by default. You can change this in Settings → Output, and click any finished item in the notification or the Recent list to show it in Finder.

Does Kumquat upload my files?

No. Every conversion runs on your Mac. Kumquat has no accounts, no analytics and does not connect to the internet. See the privacy policy.

Which formats are supported?

Images (JPG, PNG, WebP, HEIC, AVIF, TIFF, BMP, GIF, PDF), video (MP4, MOV, MKV, WebM, AVI, WMV, GIF), audio (MP3, M4A, WAV, FLAC, OGG, Opus, AIFF, WMA), PDF, documents (DOCX, RTF, ODT, TXT, Markdown, HTML, EPUB), spreadsheets (CSV, TSV, XLSX, ODS, JSON), subtitles (SRT, VTT) and archives (ZIP, TAR, GZ, RAR, 7Z).

System requirements

macOS 15 or later on a Mac with Apple silicon.

Как пользоваться

Начните перетаскивать файл в Finder или на рабочем столе и, не отпуская кнопку мыши, нажмите ⇧ Shift (конвертация), ⌘ Command (инструменты) или ⌃ Control (действия). Бросьте файл на сектор колеса — результат появится рядом с оригиналом.

Частые вопросы

Колесо не появляется.

Нажимайте клавишу во время перетаскивания, удерживая кнопку мыши. Проверьте, что жест включён (иконка в строке меню) и клавиши в настройках совпадают.

Почему Kumquat просит доступ к папке?

Приложения из Mac App Store работают в песочнице. При первом сохранении в папку macOS показывает стандартное окно — нажмите «Разрешить доступ». Если отказать, результат сохранится в «Загрузки». Список разрешённых папок — в «Настройки → Доступ к файлам».

Загружает ли Kumquat мои файлы в интернет?

Нет. Всё конвертируется на вашем Mac, приложение не подключается к интернету. Политика конфиденциальности.
